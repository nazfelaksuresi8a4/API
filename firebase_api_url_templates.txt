Anladım, * ile gizlemek değil; değişken template ({}) bırakmamı istiyorsun. Düzeltilmiş hali:

API_KEY = "{api_key}"


DB_URL = "{database_url}"
Realtime Database

GET

url = f"{DB_URL}/{path}.json?auth={id_token}"

POST / PUSH

url = f"{DB_URL}/{path}.json?auth={id_token}"

PUT

url = f"{DB_URL}/{path}.json?auth={id_token}"

PATCH

url = f"{DB_URL}/{path}.json?auth={id_token}"

DELETE

url = f"{DB_URL}/{path}.json?auth={id_token}"
Firebase Authentication

REGISTER

url = f"https://identitytoolkit.googleapis.com/v1/accounts:signUp?key={api_key}"

body = {
  "email": "{email}",
  "password": "{password}",
  "returnSecureToken": true
}

LOGIN

url = f"https://identitytoolkit.googleapis.com/v1/accounts:signInWithPassword?key={api_key}"

body = {
  "email": "{email}",
  "password": "{password}",
  "returnSecureToken": true
}

REFRESH TOKEN

url = f"https://securetoken.googleapis.com/v1/token?key={api_key}"

Değişkenler:

path = "{firebase_path}"
id_token = "{user_id_token}"
api_key = "{firebase_api_key}"
database_url = "{firebase_database_url}"

Yani gerçek değerler yerine sadece {template} alanları kaldı.
